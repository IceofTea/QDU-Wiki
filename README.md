## 如何参与维护

这项目用的是 MkDocs，写起来不算麻烦。目前有两种入坑方式：

### 🖥️ 在线编辑（适合不想装环境的朋友）

1. 先注册一个 GitHub 账号，没搞过的去[这里注册](https://github.com/signup)。
2. 在项目仓库里找到你想改的那个文件。
3. 点右上角的 **Fork this repository and edit the file** 按钮，进了编辑页面直接改。
4. **改的时候注意两点**：关掉你的自动翻译软件（不然 commit 信息会乱码），还有记得按 [Markdown 语法](https://markdown.com.cn/basic-syntax/) 来写，不然排版会崩。
5. 改完了点 **Commit changes...**，按下面的格式写 commit 信息，然后点 **Propose changes**。跳转后点绿色的 **Create pull request**，检查一遍没问题，再点一次 **Create pull request** 就完事了。
6. 等着管理员审核合并就行。

### 💻 本地编辑（适合想预览效果的朋友）

需要懂一点 Git 和命令行，但好处是可以先在本地跑起来看看效果：

- Fork 主仓库到你名下
- Clone 到你电脑上
- 装好 MkDocs 环境，改完后本地跑一遍预览
- Commit、Push，最后提 Pull Request

### 🤖 提示词工程（适合想用自然语言的朋友）

- 应该有一些基本的大模型使用经验，哪怕是进阶一些的豆包使用经验，发在交互式大模型输入框里的文字，其实就是一种“提示词”，你可以尝试按一定规则编辑自然语言，管理员收到提交后，可以利用你编辑的提示词，让Agent智能修改wiki文件，而达到一种“轻松”维护更新的效果。

- 该方法待定，仅为管理员提供一种维护思路。

1. 锁定你想要修改的部分或者希望添加的板块，编辑文字时先定位说明这是“****”目录下的哪一段内容，可以直接从wiki上复制粘贴原文。
2. 按“板块名称+原文+修改后的文本内容+期望的显示格式”，这个模式编辑到“prompt.md”文件中，注意和其他社区参与者提供的内容区分开段落。
3. 如果希望添加新的板块，按“新板块名称+目录结构+各个目录具体内容”，也可直接上传信息文档，由Agent自由发挥设计页面。

- 示例：“学院详情，学院列表理工类，计算机科学技术学院  软件工程创新实验班为特色培养项目。大一金家岭校区，大二搬至浮山校区。改为：计算机科学技术学院	计算机科学技术图灵实验班为特色培养项目，目前开设人工智能专业，有人工智能创新班，且开设算法协会，供打ACM等编程竞赛的大佬协作。期望通过css将换行长文的页面类型改成卡片左右拖动的方式展示”

## 注意事项规范

### Commit 怎么写

说白了就是让人一眼看明白你改了什么。格式参考：

```
<类型>(<文件名>): <改了什么>
```

类型有这么几种：

- `feat` — 加了新内容
- `fix` — 修了错误
- `refactor` — 大改了一个页面
- `revert` — 回退之前的改动

~~> 当然，不按这个来也没人拿你怎样，写清楚就行 😅~~

### Pull Request 怎么写

标题说清楚干了什么，内容简单写两句改了啥就行。

```
<类型>(<文件名>): <干啥了> (#对应 issue 号)
```

举个例子：

- `fix(live/eat): 更新食堂营业时间`
- `feat(new/preparation): 补充新生物品清单`
- `fix: 修复关于页面链接错误 (#42)`

## 编辑小贴士

### Markdown 排版

装个 [markdownlint](https://github.com/DavidAnson/markdownlint) 之类的插件帮你检查格式。中英文之间加个空格读起来会更舒服，具体可以看看[这份中文排版指南](https://github.com/sparanoid/chinese-copywriting-guidelines)。

### 图片怎么插

```markdown
![描述文字](图片路径或URL)
```

**图片统一放在 `docs/pics/` 目录**（Wiki 全站配图都放这里），并**按板块放入对应的子文件夹**：

```
docs/pics/
├── home/     # 首页配图
├── new/      # 新生手册
├── live/     # 生活指南
├── study/    # 学习学业
├── service/  # 校园服务
├── college/  # 学院详情
├── organization/     # 学生组织
├── share/    # 文件共享
├── words/    # 有话送你
└── about/    # 关于 Wiki
```

命名格式：

```
<文件名>-图<编号>-<描述>.png
```

比如：`study-图1-2026校历.png`（放在 `docs/pics/study/` 下）

在页面中引用时，注意根据页面所在目录写相对路径（如 `docs/study/system.md` 里用 `../pics/study/study-图1-2026校历.png`，`docs/index.md` 里用 `pics/study/study-图1-2026校历.png`）。更多说明见「[维护说明](docs/about/guide.md)」。

### 加新页面或者改目录

如果你新增了一个页面，或者想把某个页面换个位置，记得去 `mkdocs.yml` 里同步改一下导航栏配置。照着里面已有的格式抄就行。
