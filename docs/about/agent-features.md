# 智能体与社区功能使用指南

> 本站是「百科问答在 Wiki · 办事在 Nav」双站智能体体系的一半。
> 本文帮你用满它的能力——不知道的功能，欢迎在评论区问我们。

## 1. 右下角「青大智答」· 三层识别

1. **办事意图（第一层）**：输入"空教室""课表""VPN""打开智能体"等 →
   直达导航站对应功能（跨站联动，新标签打开）。导航站地址是换校落点，
   换校后自动指向新校导航。
2. **百科问答（第二层）**：基于 80 篇条目的本地 BM25 检索（`kb.json`），
   答案附「查看原文」——零外部接口、离线可用、**每条可溯源**。
3. **兜底建议（第三层）**：未命中给引导语，**不编造答案**。

## 2. 页面评论与段落批注（社区共建的真正含义）

| 功能 | 怎么用 |
|---|---|
| 发评论 | 每页底部评论区，昵称可留空（匿名）；发送前**自动敏感词校验** |
| **划选批注** | 鼠标选中正文任意句子 → 弹「✏️ 批注所选」→ 提交后该段高亮 + 📌 角标 |
| 楼中楼 | 每条评论「↩ 回复」形成楼层；支持 👍 表情表态 |
| 纠错 | 「🚩 信息有误？」→ 内容前缀 [纠错] 进维护 Agent 待办，24h 内核验 |
| 实时 | 服务器模式 **15 秒轮询**——别人的评论自动出现在你屏幕上 |
| 模式 | 🟢 服务器（跨用户共享）/ 🟡 本地（仅自己）；横幅实时明示 |

举报：每条评论右侧 🚩，填写理由进入管理台队列。

## 3. 阅读快捷键与进度

`j`/`k` 上下翻页 · `t` 回顶部 · `s` 或 `/` 聚焦搜索 · `c` 跳评论区 · `?` 快捷键卡。
页面顶部细蓝条 = 阅读进度。

## 4. 管理员入口（普通读者请忽略本节）

连点标题旁 **💬 评论徽章 5 次** → 输入口令 → 打开社区控制台；
或直接访问网关的 `/console`、`/.g/9f3a`。口令错误 5 次锁定 1 分钟。

## 5. 数据与隐私

- 配置了评论网关 → 评论存校园自托管节点（跨用户共享）
- 未配置 → 评论存你自己浏览器（localStorage），**不上传任何第三方**
- 敏感词名单由管理员实时维护，命中即拦截（发送前前端预检 + 服务端二道闸）
