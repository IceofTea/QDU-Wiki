## 学院简介

青岛大学艺术学院涵盖音乐、舞蹈、美术与设计等多个艺术门类，面向艺术创作与艺术教育培养人才。

> 学院详细师资、学科平台等信息待更新。

## 专业设置

| 专业 | 说明 |
| --- | --- |
| **音乐学** | 音乐理论、音乐教育方向 |
| **音乐表演** | 声乐、器乐表演方向 |
| **舞蹈学** | 舞蹈表演与编导方向 |
| **绘画** | 油画、国画等造型艺术方向 |
| **环境设计** | 室内外环境与空间设计方向 |
| **视觉传达设计** | 平面设计、品牌视觉方向 |
