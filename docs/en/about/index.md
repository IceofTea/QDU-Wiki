# About Wiki

## Project Overview

**Qingdao University Wiki** is an unofficial campus guide, jointly maintained by all members of Baidu Tieba [Qingdao University Bar] and enthusiastic alumni. It aims to provide comprehensive, multi-dimensional campus information reference for new and old students, helping every Qingdao University member better understand the campus.

This guide initially originated from an early Word document edited by "Advertising Brother," and was later continuously supplemented and improved by bar members, finally adopting the wiki format to make information access more convenient and content maintenance more efficient.

## How to Contribute

Due to issues such as information timeliness, hurried construction, one person cannot simultaneously study 90 undergraduate majors, etc., this guide always has many areas needing improvement.

If you find any issues or have new content to supplement, you are welcome to participate through the following methods:

### Method 1: Direct GitHub Contribution

1. Visit the [project GitHub repository](https://github.com/IceofTea/QDU-Wiki)
2. Fork this project
3. Modify or add content
4. Submit a Pull Request

### Method 2: Submit an Issue

Submit an Issue in the GitHub repository, describing the problem you found or the content you wish to supplement.

### Method 3: Contact Tieba

Post in [Baidu Tieba [Qingdao University Bar]](https://tieba.baidu.com/f?kw=%E6%99%8B%E5%8F%96%E4%BA%86%E5%90%97) or contact the bar administration team.

### Method 4: Tencent Docs (Zero threshold, recommended)

Find GitHub difficult? You can directly open the [Qingdao University Wiki Campus Guide Tencent Docs](https://docs.qq.com/aio/DVFJnbFR3TWdzbFVn), log in and **directly edit and supplement** by section. Administrators will regularly sync back to this site. Suitable for friends unfamiliar with Git who just want to add a piece of information.

### For Initial Maintainers:

"I" have temporarily marked all information that I think needs maintenance with a "To be updated" warning box at the top of the page, which can be quickly located using the search bar. After the initial maintenance is completed, future bar administrators can also adopt similar methods, but I think there might be more convenient development methods in the distant future.

!!! tip "Want to participate in maintenance?"
    For detailed methods of uploading files, images, and local deployment, see [Maintenance Guide](guide.md); for Tencent Docs maintenance methods, see [Maintenance Guide · Tencent Docs Maintenance](guide.md).

## Statement

This wiki has borrowed to some extent from the "Shanghai Jiao Tong University Survival Manual" and many other university students' self-maintained wiki websites, such as QFNU, FJNU, XUPT, USTC. One of the developers fantasized in 2024 about integrating the materials at hand into a wiki format, but due to multiple reasons, even the project initiation was not achieved. Not long after, in 2026, thanks to the development of large models and the application of Agents, this wiki (or rather, this old information integration platform that the developer gave birth to but didn't nurture) came into being.
