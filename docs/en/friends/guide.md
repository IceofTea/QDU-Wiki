# Friend Link Application

We welcome university Wiki sites and campus guide projects to apply for mutual friend links. Below are the requirements and process.

## Requirements

- Unofficial campus guide or Wiki site for university students
- Healthy, positive content with no illegal information
- Site is accessible and maintained
- Non-commercial student-run project

## How to Apply

Please submit an application via our [GitHub Issues](https://github.com/IceofTea/QDU-Wiki/issues/new?title=%E5%8F%8B%E6%83%85%E9%93%BE%E7%94%B3%E8%AF%B7&labels=%E5%8F%8B%E6%83%85%E9%93%BE) using this format:

| Item | Content |
| --- | --- |
| **Site name** | Your site name |
| **Site URL** | Your site URL |
| **Description** | One-line intro (within 30 words) |
| **Site Logo** | Logo image link (200×200px or smaller recommended) |
| **Screenshot** | Homepage screenshot link (1200×630px recommended) |
