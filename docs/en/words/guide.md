# Guide

This page explains the Messages board for maintainers. Back to [Messages home](index.md).

## About This Board

This board is **reserved** for messages seniors want to pass on to freshmen. It will be curated by community maintainers.

- Any format works: one line, one paragraph, or a letter
- Sign it or stay anonymous
- Collection method and update cadence will be announced by maintainers

## How to Maintain

- Append messages to the collection in `docs/words/index.md` using Markdown. No code needed
- Each message should note class year + college + message, so freshmen can relate

**Format:**

```markdown
### Signature (anonymous OK, class year/college optional)

Your message here…

> —— Signature
```

!!! example "Example"
    ```markdown
    ### YanhuangYH

    Every college life has its own meaning. Focus on value, not cost…

    > —— YanhuangYH
    ```

- Anonymous messages can skip the signature
- Separate messages with `---` to keep the layout clean
