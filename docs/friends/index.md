!!! info "申请友链"
    我们欢迎各高校 Wiki 站点、校园指南类项目申请互换友链。
    
    **申请条件：**
    
    - 面向高校学生的非官方校园指南或 Wiki 站点
    - 内容健康、积极，无违法违规信息
    - 网站可正常访问，更新维护正常
    
    **申请方式：**
    
    请前往本站 [GitHub Issues](https://github.com/IceofTea/QDU-Wiki/issues/new?title=%E5%8F%8B%E6%83%85%E9%93%BE%E7%94%B3%E8%AF%B7&labels=%E5%8F%8B%E6%83%85%E9%93%BE) 提交申请，按以下格式填写：
    
    | 项目 | 内容 |
    | --- | --- |
    | **站点名称** | 你的站点名称 |
    | **站点链接** | 你的站点 URL |
    | **站点描述** | 一句话介绍（30 字以内） |
    | **站点 Logo** | Logo 图片链接（建议 200×200px 以内） |
    | **网站截图** | 首页截图链接（建议 1200×630px） |
