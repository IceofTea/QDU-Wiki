# 提示词工程 — 让 AI 帮你维护 Wiki

## 这是什么

你平时和豆包、ChatGPT 对话时输入的文字，就是一种"提示词"。这里的思路是：**你按固定格式写好修改需求，管理员把它丢给 AI Agent，Agent 就能自动改好对应的 Markdown 文件并提 PR**，省去手动编写排版的麻烦。

## 基本格式

```
定位 + 原文 + 修改后的内容 + 期望的显示格式
```

1. **定位**：说明是哪个目录下的哪个文件，可以直接粘贴原文
2. **修改内容**：要改成什么样
3. **显示格式**：渲染效果上的要求（可选，不写则沿用原文格式）

## 示例

> **定位**：`docs/college/index.md` 第 3-7 行
>
> **原文**：
>
> ```markdown
> 青岛大学现有以下学院（学部）：
>
> 医学部、数学与统计学院、……计算机科学技术学院、……
> ```
>
> **改为**：在计算机科学技术学院后补充说明"图灵实验班为特色培养项目，开设人工智能专业，有人工智能创新班及算法协会"
>
> **格式**：希望将现有的平铺文本改为卡片式展示，每张卡片包含学院名称、特色标签、一句话介绍

## 新增板块格式

```
新板块名称 + 期望的目录结构 + 各目录具体内容
```

可以直接上传参考文档，由 Agent 自由设计页面结构。

## 注意事项

- 尽量写清楚定位，避免模糊表达
- 多个修改建议之间用段落或 `---` 隔开
- 不强制使用本格式，但遵循格式会让 Agent 处理更准确

## 提示

- 你也可以直接把你头脑中的“信息源”以回忆录的形式敲出来，无需在意格式与语言通顺程度，编辑好后直接复制粘贴到任意生成式大模型网站中，并将下面这段话复制粘贴到文本开头或末尾
- “你现在是一个提示词工程师，这些文本是我关于青岛大学相关信息的整理内容，我需要利用这些信息维护青岛大学的维基百科网站，为了更好地利用好这些信息，请你根据这些文本，为Agent编辑好提示词，便于Agent的工作，尽量维持信息完整性，同时兼顾无意义的Token浪费。”
- AI将生成好的提示词输出给你后，即可复制粘贴到下面并申请pull request
